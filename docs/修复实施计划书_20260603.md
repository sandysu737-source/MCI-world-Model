## 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| su_memory API 签名字段不兼容 | 中 | 中 | 先在测试环境验证 EnergyCore 接口签名；必要时在 `_world_model.py` 中添加 adapter 层 |
| mypy 注解补全触发运行时破坏 | 低 | 高 | 仅在 `TYPE_CHECKING` 块和 stub 中使用 `from __future__ import annotations`；每模块修复后即刻全量测试 |
| ruff 自动修复改变代码语义 | 低 | 中 | `ruff --fix --diff` 预览后再执行；git diff 逐条审查 |
| 测试数量增长引入 flaky tests | 中 | 中 | 新测试必须连续 3 次 passing 才算通过；CI 中禁用 `--random-order` |
| 第二阶段与 P9 并行开发产生合并冲突 | 中 | 低 | 使用独立分支；每周合并主分支一次；冲突时优先本计划变更 |
