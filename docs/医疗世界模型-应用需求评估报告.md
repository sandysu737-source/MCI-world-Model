# MCI World Model — 医疗智能体世界模型应用需求评估报告

> 评估日期：2026-07-17  
> 评估范围：项目当前状态 vs 医疗领域智能体世界模型的落地需求

---

## 一、总体判断

**项目在"因果推理引擎"层面是优秀的，但在"医疗智能体世界模型"层面还差关键几步。**

核心矛盾：项目拥有极强的通用因果推理能力（Pearl 三层 + JEPA + 能量中心），但这些能力目前**悬浮在真实医疗场景之上**——没有接真实数据标准、没有在真实临床数据上验证、三大核心模块之间没有打通。

一句话总结：**"引擎很强，但还没有装到车上"**。

## 三、三大核心问题（按严重程度排序）

### 问题 1：模块集成断裂（P0，最严重）

代码检查发现三个核心模块**互相不调用**：

- `ClinicalTriRouter`（路由）不调用 `MCIWorldModel`（世界模型）的因果发现能力
- `MedicalCausalSDK`（医疗 SDK）不调用 `ClinicalTriRouter`（路由）
- `MCIWorldModel` 不调用 `ClinicalTriRouter`

这意味着：世界模型能发现的因果图喂不到路由器，路由器的决策结果传不到医疗 SDK。三个模块各自独立运行，**不是一个系统，是三个独立玩具**。

### 问题 2：零真实数据验证（P0）

- JEPA 预测器**从未**在真实生理波形（MIMIC-III 波形数据）上验证
- MIMIC benchmark 的 ground truth 是**专家手写的共识因果边**（37 条），不是从数据中发现的
- 路由准确率 88% 是在 **60 条手写合成查询**上测的，不是真实临床场景
- 临床营养 benchmark 只有 **10 个案例**

### 问题 3：无医疗数据标准对接（P0）

搜索全代码库，**找不到任何** FHIR / HL7 / ICD-10 / SNOMED CT / LOINC / ATC / RxNorm 的对接代码。这意味着系统无法接收任何医院信息系统的真实数据。

## 五、已有优势（不能丢）

1. **Pearl 因果三层完整**：关联 → 干预 → 反事实，这是绝大多数"AI 医疗"产品不具备的深度
2. **JEPA 世界建模**：潜空间预测 + 能量约束，区别于纯黑箱深度学习
3. **三元融合路由**：物理路径 + 因果 + 语义，已申请专利
4. **能量中心**：能量守恒约束 + 生克关系，提供可解释的物理约束
5. **BGE-M3 语义检索**：1024 维原生中文嵌入，知识库检索能力已验证
6. **4327 项测试**：工程质量扎实，CI 4-Gate 全绿

---

## 六、结论

项目的**技术内核是世界级的**（因果 + JEPA + 能量中心的组合在学术界也属前沿），但距离**医疗智能体的应用需求**还有明确的、可量化的差距。

好消息是：这些差距都是**工程问题**，不是理论问题。不需要重新发明算法，需要的是：
1. 把已有模块**接起来**（P0-1）
2. 接上**真实数据标准**（P0-2）
3. 在**真实数据上跑通**（P0-3）

完成 P0 三项后，项目就能从"论文级原型"升级为"可演示的医疗决策支持系统"。
