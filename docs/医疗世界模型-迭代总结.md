# MCI World Model — 医疗智能体世界模型迭代总结

> 日期：2026-07-17  
> 方法论：第一性原理（First Principles Thinking）  
> 目标：从"因果推理工具箱"升级为"完整的医疗智能体世界模型"

---

## 一、迭代起点：第一性原理诊断

用世界模型五要素（状态 S、动作 A、转移 T、评估 R、规划 π）审计代码，发现：

**项目的"世界模型"只在物理玩具域（单摆/小车）上成立。医疗部分是一组并行的因果推理工具，从未被建模为世界模型。**

| 要素 | 医疗要求 | 迭代前现状 | 结论 |
|------|---------|----------|------|
| 状态 S | 异构临床时序 | PendulumState（单摆） | 🔴 缺失 |
| 动作 A | 药物+剂量+途径 | PendulumAction（力矩） | 🔴 缺失 |
| 转移 T | 临床动态学 | 单摆物理方程 | 🔴 缺失 |
| 评估 R | SOFA+安全约束 | 欧氏距离 | 🔴 缺失 |
| 规划 π | 可解释治疗搜索 | 玩具 MCTS | 🔴 缺失 |

## 二、四层重建路线（从地基往上建）

### Phase 0：状态+动作空间（地基）

| 模块 | 文件 | 核心内容 |
|------|------|---------|
| PatientState | `_clinical_world_state.py` | 7 维体征时序 + 6 维检验值 + 用药 + 诊断 + SOFA 评分 + 安全约束 |
| MedicalAction | 同上 | 6 种药物 one-hot 编码 + 剂量 + 给药途径 |
| ClinicalStateEncoder | `_clinical_state_encoder.py` | 三种输入模式：体征字典 / FHIR R4 Observation / numpy 矩阵 |

**关键技术决策**：
- PatientState 继承 WorldState ABC，实现 to_vector/from_vector/distance/copy 四契约
- MedicalAction 加入 DRUG_REGISTRY one-hot 编码（解决"所有药物动作向量相同"问题）
- LOINC 代码映射（8867-4→heart_rate 等 7 种核心体征 + 6 种检验）

### Phase 1：转移模型 T（核心）

| 模块 | 文件 | 核心内容 |
|------|------|---------|
| ClinicalDynamicsPredictor | `_clinical_dynamics.py` | T(s,a)→s'，继承 ActionConditionedPredictor |
| UncertainPrediction | 同上 | 贝叶斯 bootstrap 95% 置信区间 |

**训练模式**：
- `fit_from_effect_table()` — 从药效基线表（6 种药物 × 正常体征范围）生成 (s,a,s') 三元组
- `fit_from_trajectories()` — 从真实时序轨迹学习（MIMIC/波形数据）

**关键技术突破**：
- **标准化层**：体征值（60-220）和动作值（0-10）量纲差异曾导致 NaN 梯度爆炸。通过 normalize/denormalize 映射到 [-1,1]，loss 从 0.19→0.06
- **药物区分**：加入 DRUG_REGISTRY one-hot 后，模型终于能区分多巴胺（↑心率）和美托洛尔（↓心率）

**波形验证结果**：
- ✅ 药物效应预测 4/4 方向正确（多巴胺↑↑、美托洛尔↓↓、去甲肾上腺素↑SBP↓HR、肾上腺素↑↑）
- ✅ 物理约束违反率 0%
- ❌ 波形自然演化方向准确率 ~47%（纯 MLP 无时间记忆，需 RNN/LSTM 升级）

### Phase 2：评估+规划闭环

| 模块 | 文件 | 核心内容 |
|------|------|---------|
| ClinicalObjective | `_clinical_objective.py` | R(state)→[0,1]，三维度：体征稳定度 + 器官功能(SOFA) + 安全约束 |
| ClinicalMCTSPlanner | `_clinical_planner.py` | π：搜索最优药物干预序列，含 compare_actions 和 recommend_best |
| TreatmentPlan | 同上 | 治疗方案输出（含 top-3 方案对比 + 预测轨迹） |

### Phase 2-3：编排层 + 不确定性 + 语义检索

| 模块 | 文件 | 核心内容 |
|------|------|---------|
| ClinicalDecisionEngine | `_clinical_decision_engine.py` | 五要素编排：编码→路由→（规划/检索）→评估→安全降级 |
| 不确定性量化 | `_clinical_dynamics.py` | predict_with_uncertainty() 贝叶斯 bootstrap 95% CI |
| BGE-M3 语义检索 | `_clinical_decision_engine.py` | semantic 路径接入 SemanticKnowledgeBase（含 BGE-M3） |

## 四、ICU Demo 四场景验证

| 场景 | 路由 | 推荐动作 | Δreward | 不确定性 | 安全等级 |
|------|------|---------|---------|---------|---------|
| 心动过速(HR=130) | causal | 美托洛尔 8.0 | +0.076 | 0.098 | ✅ trusted |
| 低血压休克(SBP=75) | causal | 去甲肾上腺素 3.0 | +0.151 | 0.085 | ✅ trusted |
| 正常体征(对照) | fused | 呋塞米 5.0 | -0.032 | 0.103 | ⚠️ needs_review |
| 知识问答 | semantic | 📚去甲肾上腺素 | +0.005 | 0.108 | ✅ trusted |

**临床正确性**：
- 心动过速 → β受体阻滞剂（美托洛尔）✅
- 低血压休克 → 升压药（去甲肾上腺素）✅
- 正常患者 → 所有药物降低 reward → 正确标记需复核 ✅
- 知识问答 → BGE-M3 检索到正确指南条目 ✅

## 五、不确定性量化示例

多巴胺 5μg 预测心率：**86.9 [95% CI: 84.9 - 88.2]**

- 点估计：86.9 bpm
- CI 宽度：3.3 bpm
- 不确定性分数：0.103（低于阈值 0.3 → 可信输出）
- 三级安全降级：低置信+高不确定→REFUSED；任一触发→NEEDS_REVIEW；全通过→TRUSTED

| 状态编码/转移预测/评估/规划 | MCI World Model | ✅ 全部在此 |

## 七、已知局限与后续方向

| 局限 | 根因 | 改进方向 |
|------|------|---------|
| 波形自然演化准确率 ~47% | 纯 MLP 无时间记忆 | 升级为 RNN/LSTM/TCN 时间感知架构 |
| 药效表是定性量级 | 非精确药代动力学 | 接入真实药代动力学模型 / 从 EHR 数据学习 |
| 知识库仅 6 条手写条目 | 未灌入真实指南 | 批量导入脓毒症/ACLS/血流动力学指南 |
| MCTS 简化为一步前瞻 | 完整 MCTS 计算量大 | 启用完整 MCTS 搜索（已有 MCTSPlanner 基础设施） |

## 八、从"工具箱"到"世界模型"的本质变化

迭代前：ClinicalTriRouter + MedicalCausalSDK + CausalDAG = **三个独立的因果推理工具**

迭代后：PatientState → ClinicalStateEncoder → ClinicalDynamicsPredictor → ClinicalObjective → ClinicalMCTSPlanner → ClinicalDecisionEngine = **完整的感知-预测-行动闭环**

这不是把工具粘在一起，而是从世界模型的本质定义出发，构建了一个能回答"如果我做 X 会怎样""最优行动是什么""结果好不好""我有多确定"的完整医疗世界模型。
