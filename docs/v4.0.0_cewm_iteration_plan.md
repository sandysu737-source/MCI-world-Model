# MCI World Model v4.0.0 CEWM 迭代实施规划书

> **版本路径**: v3.3.0 → v3.4.0 → v3.5.0 → v3.6.0 → v3.7.0 → **v4.0.0**
> **基线**: 65 模块 / ~40,000 行 / 1,678 passed + 4 xfailed / 零 regression
> **理论框架**: 认知增强世界模型 (CEWM) — Kant-Ashby-Lakatos 三维理论基础
> **文档密级**: 内部技术文档（遵循 MCI 产品矩阵脱敏规则）

---

## 一、战略定位

### 1.1 范式跃迁

```
v3.3.0 「多模态因果世界模型」
  核心：Pearl 三层因果 + JEPA 世界建模 + 能量中心三才合一
  定位：独立因果推理引擎（CPU 隐喻）

v4.0.0 「认知增强世界模型」
  核心：因果理解 + 经验记忆 + 自适应控制 + 认知诊断
  定位：从 Pearl 因果推理引擎升级为 CEWM 认知增强引擎
  理论：Kant 先验范畴计算化 + Ashby 必要多样性 + Lakatos 进步性
```

### 1.2 升级原则

| 原则 | 说明 |
|------|------|
| **硬核不可放弃** | Pearl 三层因果 + 能量中心三才合一 = CEWM 的硬核，不降级 |
| **保护带可替换** | JEPA 编码器/预测器、频谱因果、参数化记忆 = 可替换保护带 |
| **渐进式升级** | 每个 Phase 独立可验证，不阻塞 v3.x 的维护发布 |
| **向后兼容** | 新增组件不破坏 `__init__.py` 现有 200 个导出符号 |

## 二、架构缺口总览

| 认知能力 | v3.3.0 实现度 | v4.0.0 目标 | 核心缺口 |
|---------|-------------|-----------|---------|
| 因果理解 | **72%** | 95% | 缺自动因果发现 + 因果图自适应更新 |
| 经验记忆 | **45%** | 85% | MultiViewRetriever=None 占位符 + 缺 ExperienceDB |
| 自适应控制 | **58%** | 90% | 缺四层跨层反馈总线 CognitiveLoopBus |
| 认知诊断 | **25%** | 80% | MetaCognition 仅 56 行 + 缺 MetaDiagnoser |

**Beer VSM 对标**:
- System 5 (政策与身份) 薄弱 → MetaCognition 需从规则检测升级为学习型策略
- System 3* (异常审计) 仅有检测 → 需补全根因分析链

**Wiener 四层反馈**:
- 四层基本独立运行 → 缺跨层误差传播方程 Δθ_l(t) = -α∇‖e‖² + β·e_{l-1}(t)
