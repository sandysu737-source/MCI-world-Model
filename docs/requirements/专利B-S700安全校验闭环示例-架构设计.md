# 架构设计输出：专利B S700 安全校验闭环可复现示例

> 必须人工审核通过后合入。审核不通过禁止合入。

## 1. 模块职责
新增独立子包 `src/mci_world_model/nutrition/`，与现有 `sdk/`、`algebra/`、`server/` 完全解耦，仅提供专利B 方案的可复现实现；测试放 `tests/test_nutrition_conflict_solver.py`。
2026-08-19 口径升级：S700 蛋白质校验由"系数口径"改为"热量口径"——校验对象为上一步 S620 输出的蛋白质热量（含 FFM 修正后的真实目标），基准 = 最严格蛋白质上限 × 体重 × 4 kcal/g × (1 + 15%)，与权利要求 9 及代理批注一致。

## 2. 模块拆分
| 文件 | 职责 |
|------|------|
| `nutrition/conflict_solver.py` | 主实现：S100–S800 全流程 + 数据类 + 示例规则库 |
| `nutrition/__init__.py` | 导出公共符号 |
| `tests/test_nutrition_conflict_solver.py` | 实施例 1–6 + 边界 + 异常 |

数据类：
- `DiseaseConstraint`（冻结）：name / keywords / protein_min / protein_max / stress / fluid_rule / fluid_factor / priority / specialist / score
- `SafetyConfig`：protein_tolerance=0.15、fluid_tolerance_ml_per_kg=5.0、liquid_min=1000、liquid_max=4000、energy_min=800、energy_max=4000、default_fluid_factor=30.0、bmr_kcal_per_kg=25.0
- `NutritionPlan`（输出）：见需求文档 §3
- `PairRule`：disease pair + 回调策略（示例：Parkland 液体量、蛋白保持）

## 3. 依赖关系
- 内部：仅标准库（dataclasses / re / typing）
- 外部：无
- 不引入 numpy/torch（纯数值，避免重依赖）

## 4. 接口设计
```python
solve_nutrition_plan(
    diagnosis_text: str,
    weight_kg: float,
    *,
    ffm_kg: float | None = None,
    ffm_correction: float = 1.0,
    burn_area_pct: int | None = None,
    activity_factor: float = 1.0,
    disease_rules: tuple[DiseaseConstraint, ...] | None = None,
    pair_rules: tuple[PairRule, ...] | None = None,
    config: SafetyConfig | None = None,
) -> NutritionPlan
```
内部函数（单一职责，≤80 行/函数）：`parse_diagnosis` / `match_constraints` / `apply_dialysis_cover` / `solve_protein_interval` / `solve_fluid_strategy` / `apply_pair_rules` / `compute_targets` / `safety_check` / `build_warnings`。

## 5. 数据层设计
无 DB。示例规则库为模块内只读常量（值取自说明书实施例 1–6；实施例未给出处标注为示例值），可经参数注入替换。

## 6. 安全设计
无鉴权/脱敏需求；无硬编码路径与密钥；输入仅做数值范围校验（体重/FFM > 0）。

## 7. 可扩展预留点
- 约束词典/疾病对规则库可注入替换（外部配置化）
- `ffm_correction` 支持水肿/腹水级联系数
- 输出结构稳定，便于后续接入生产营养引擎

## 8. 风险点与规避方案
| 风险 | 规避 |
|------|------|
| 与生产 sdk 命名/语义冲突 | 独立子包 `nutrition/`，不 export 进 sdk 顶层 |
| 数值与说明书实施例不符（捏造风险） | 测试逐例断言说明书数值（0.8 / 1.1 / 1.0 / 1.2 / 42.1 / 8400-2100） |
| 规则库示例值被误认为临床真值 | 模块 docstring 与常量注释明确"示例值，非临床指南" |
| 热量口径基准定义不清（体重/FFM、上限/冲突系数歧义） | 基准写死：最严格蛋白质上限 × 体重 × 4 kcal/g × (1+15%)；无 FFM 修正场景与系数口径数值完全等价 |
| FFM 输入误差导致热量口径偏松 | FFM 缺失/可疑时回退体重口径（`ffm_kg=None` 时 basis=体重），后续可加数据质量守卫 |
