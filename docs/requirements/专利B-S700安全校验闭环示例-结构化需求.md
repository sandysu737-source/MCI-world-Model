# 结构化开发需求：专利B S700 安全校验闭环可复现示例

> 本示例为专利答复配套实验证据，非生产业务功能。源方案见专利《基于区间交集代数的多疾病并存营养冲突求解方法及系统》（说明书 S100–S800、实施例 1–6）。

## 1. 业务目标
把专利B 说明书 S100–S800 核心流程沉淀为可复现的 Python 模块 + pytest，重点可复现验证 **S700 安全校验闭环**：
- 蛋白质：最终输出的蛋白质热量(kcal)（= 蛋白质目标 × 4 kcal/g，蛋白质目标含 FFM 修正）不得超过最严格蛋白质上限(g/kg) × 体重(kg) × 4 kcal/g × (1+15%)；校验对象为上一步 S620 的输出；
- 液体：疾病要求限液时，最终输出的液体量(ml/d) 不得超过 限液液体因子×体重 + 5ml/kg×体重；
- 任一校验失败 → 标记不通过并回退规则引擎。

## 2. 输入参数定义
| 字段 | 类型 | 必填 | 默认 | 校验规则 |
|------|------|------|------|----------|
| diagnosis_text | str | 是 | - | 非空；含疾病关键词 |
| weight_kg | float | 是 | - | > 0 |
| ffm_kg | float\|None | 否 | None | > 0（存在时优先用于蛋白目标） |
| ffm_correction | float | 否 | 1.0 | (0, 1]（水肿 0.9 / 腹水级联 0.85 示例） |
| burn_area_pct | int\|None | 否 | None | ≥ 0（烧伤面积%，触发 Parkland 规则） |
| activity_factor | float | 否 | 1.0 | > 0 |
| disease_rules | 规则集 | 否 | 内置示例词典 | 含必需字段 |
| pair_rules | 规则集 | 否 | 内置示例规则库 | - |
| config | SafetyConfig | 否 | 默认 | - |

## 3. 输出数据结构
`NutritionPlan`（dataclass，固定结构）：
- `matched: bool`、`diseases: list[str]`（匹配疾病标准名）
- `protein_coef: float|None`（g/kg）、`protein_target_g`、`energy_target_kcal`、`liquid_target_ml`
- `protein_kcal`、`fat_kcal`、`carb_kcal`（三大营养素分配）
- `final_fluid_volume_ml`（S500 规则叠加后的最终输出液体量，默认=液体目标）
- `protein_check_pass`、`fluid_check_pass`、`safety_pass`（S700 结果）
- `fallback: bool`（校验失败是否触发回退规则引擎）
- `dialysis_covered: bool`、`warnings: list[str]`（S800 预警）

## 4. 依赖资源
无外部服务/DB。仅 Python 标准库（dataclasses / re / typing）。

## 5. 业务流程步骤（对应说明书）
S100 诊断解析 → S200 约束匹配（子串匹配+去重+专科覆盖通用）→ S300 透析覆盖 → S400 冲突求解（S410 评分 max / S420 应激系数 max / S430 蛋白质区间交集 / S440 液体策略）→ S500 循证疾病对规则叠加 → S600 目标计算（能量/蛋白质/液体 + 三大营养素分配）→ S700 安全校验闭环（失败回退）→ S800 预警输出。

## 6. 边界条件
- [x] 空值：诊断文本为空/无匹配 → matched=False + 预警，不抛异常
- [x] 上下限：液体目标钳制 [1000, 4000] ml/d；能量目标钳制 [800, 4000] kcal/d
- [x] 容差边界：蛋白质热量 == 最严格上限×体重×4×1.15 判通过，> 判失败；液体量 == 限液因子×体重+5×体重 判通过，> 判失败
- [x] FFM 修正场景：FFM×修正系数 < 体重时，热量口径与系数口径判定可不同（校验最终输出值，而非中间系数）
- [ ] 重复：同标准名多条约束按最小优先级去重（已实现）
- [ ] 过期/禁用：不适用（无状态数据）

## 7. 异常场景
- 体重 ≤ 0 → ValueError
- 无匹配疾病 → 空方案 + 预警，不崩溃
- FFM ≤ 0 → ValueError

## 8. 性能约束
- 规则库为小规模常量集（线性扫描），无循环/超时约束。

## 9. 安全约束
- 无密钥/敏感字段；示例数据全部来自说明书实施例；不硬编码路径。

## 10. 必须覆盖测试用例
1. 正向：实施例 1–6 数值复现（胃癌+肾病 0.8 / 透析 1.1 / 肝硬化+糖尿病 1.0 / 心衰+烧伤 1.2+restrict25 / FFM 腹水 42.1g / Parkland 8400>2100 回退）
2. 边界：液体/能量钳制、蛋白质 15% 容差边界、限液 5ml/kg 容差边界
3. 异常：空诊断、非法体重、FFM 非法
